# DS-Controller

A custom, modern Nintendo DS-inspired touchscreen controller
for PC emulation.

## Design Goals

- 5-inch touchscreen, preferably 4:3
- Clicky Nintendo DS-style D-pad
- ABXY, L/R, Start, Select
- No analog sticks
- Single USB-C connection for wired gameplay and charging
- Wireless gameplay over Wi-Fi
- Rechargeable battery with a 5-hour runtime target
- Windows and Linux compatibility

## Hardware Design

Designed using KiCad 10.

## Project Status

Early schematic and hardware development.
